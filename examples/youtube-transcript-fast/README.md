# YouTube transcript API - Python, n8n and LangChain example

> **[Run it on Apify](https://apify.com/highbrow_fame/youtube-transcript-fast)** - **YouTube Transcript API & Subtitles Scraper** pulls captions for videos, playlists or whole channels - plain text, timed segments, plus optional SRT and VTT - for RAG, summarisation and content pipelines.

Copy-paste integration examples for the [youtube-transcript-fast](https://apify.com/highbrow_fame/youtube-transcript-fast) Apify actor: call it from **Python**, an **n8n** workflow, or a **LangChain** agent. You need a free Apify account and an API token (`APIFY_TOKEN`). Start with a small limit to see the output, then scale up.

Keywords: youtube transcript api, youtube subtitles scraper, youtube captions python, youtube transcript n8n, youtube transcript langchain, rag.

## What you can build

- Feed video transcripts into a RAG index
- Summarise new videos from a channel with n8n and an LLM
- Give an agent a 'read this YouTube video' tool

## What you get (output fields)

Field names from the actor's dataset schema:

| Field | Meaning |
|---|---|
| `videoId, url, title, channel, channelId` | Which video it is |
| `lengthSeconds, viewCount` | Video stats |
| `status, error` | Per-video result, so one bad link never hides the rest |
| `language, isAutoGenerated, availableLanguages` | Caption language details |
| `text` | Full transcript as plain text |
| `segments, segmentCount` | Timed caption segments |
| `srt, vtt` | Subtitle files (with includeSrt / includeVtt) |

Example item (shortened; values are made-up placeholders, not real data):

```json
{
  "videoId": "aircAruvnKk",
  "title": "Example video title",
  "channel": "Example Channel",
  "status": "ok",
  "language": "en",
  "isAutoGenerated": true,
  "segmentCount": 412,
  "text": "Transcript text starts here ..."
}
```

## 2. n8n (`n8n_workflow.json`)

Import [n8n_workflow.json](n8n_workflow.json) (Workflows -> Import from file). It is Manual Trigger -> HTTP Request, which POSTs to the `run-sync-get-dataset-items` endpoint and returns the dataset items directly.

- Provide the token as an `APIFY_TOKEN` environment variable on your n8n instance. If your n8n blocks env access in nodes, use an HTTP Header Auth credential (`Authorization: Bearer <token>`) instead of the URL token.
- The sync endpoint waits up to about 5 minutes. For bigger jobs use the async run endpoint or the official Apify node, then fetch the dataset when the run finishes.
- Connect the output to Google Sheets, Airtable, Slack, a CRM or an LLM node.

## 3. LangChain agent (`langchain_tool.py`)

```bash
pip install langchain-apify langchain langgraph langchain-openai
export APIFY_TOKEN=your_token OPENAI_API_KEY=your_key
python langchain_tool.py
```

[langchain_tool.py](langchain_tool.py) wraps the actor with `ApifyActorsTool`, so an agent can call it like any other tool. Example prompt: *"Get the transcript of https://www.youtube.com/watch?v=aircAruvnKk and summarise it in 5 bullets."* Swap in any LangChain chat model.
