# Integration examples: Apify actors from Python, n8n and LangChain

Ready-to-copy examples that call Apify Store actors by [highbrow_fame](https://apify.com/highbrow_fame) from **Python** (`apify-client`), **n8n** (HTTP Request node) and **LangChain** (`langchain-apify`). Each folder has a README, `python_example.py`, `n8n_workflow.json` and `langchain_tool.py`.

| Use case | Example | Run it | Code |
|---|---|---|---|

| AI search visibility tracking | [AI Brand Monitor - AI Search Visibility Tracker](ai-search-visibility-tracker/README.md) | [Run it on Apify](https://apify.com/highbrow_fame/ai-search-visibility-tracker) | [Python](ai-search-visibility-tracker/python_example.py), [n8n](ai-search-visibility-tracker/n8n_workflow.json), [LangChain](ai-search-visibility-tracker/langchain_tool.py) |
| ImmoScout24 Austria property listings API | [ImmoScout24 Austria Scraper](immoscout24-at-properties/README.md) | [Run it on Apify](https://apify.com/highbrow_fame/immoscout24-at-properties) | [Python](immoscout24-at-properties/python_example.py), [n8n](immoscout24-at-properties/n8n_workflow.json), [LangChain](immoscout24-at-properties/langchain_tool.py) |

| Magicbricks India property listings API | [Magicbricks Scraper](magicbricks-properties/README.md) | [Run it on Apify](https://apify.com/highbrow_fame/magicbricks-properties) | [Python](magicbricks-properties/python_example.py), [n8n](magicbricks-properties/n8n_workflow.json), [LangChain](magicbricks-properties/langchain_tool.py) |
