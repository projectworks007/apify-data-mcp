Data reports: live numbers, rebuilt on a schedule

Three small, repeatable data reports on rents, supermarket prices and tech jobs. Each one is collected from live websites by an Apify actor with a fixed input, then summarised with plain arithmetic, so the numbers can be checked and the next edition is comparable with this one.

Each report shows its method, sample size and caveats. Aggregates only: no personal data, listing texts or ad texts.
